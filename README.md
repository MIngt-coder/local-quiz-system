# 期末速测台

一个运行在本机的复习测验系统。上传 Word、PDF 或 TXT 题目文档后，可以核对识别结果、保存题库、进行逐题练习或模拟考试，并根据错题查看薄弱考点。

## 启动

首次使用：

```powershell
npm install
npm start
```

看到启动提示后，在浏览器打开：

```text
http://localhost:4173
```

## 使用顺序

1. 在“导入资料”中选择 `.docx`、`.pdf` 或 `.txt` 文件。
2. 在核对区域检查题型、题干、选项、答案、解析和考点。
3. 确认入库。
4. 在“开始速测”中选择练习模式或模拟考试。
5. 在“复盘记录”中点击历史测验查看每题结果，或从薄弱考点直接开始强化练习。

识别规则调整后，如果需要重新处理已经导入的旧文档，可以在“我的题库”中按上传文档整批删除，再重新上传原文档。删除前页面会再次确认。

## 当前边界

- PDF 必须带有可复制的文字层，扫描图片暂不支持。
- 简答题显示参考答案，供自行核对，不自动计分。
- “模型设置”页面只保存兼容 OpenAI 格式的接口信息，首版不会联网调用。
- 数据保存于本机 `data/quiz.sqlite`。
