# 期末速测系统设计说明

## 1. 目标

做一个简洁的本机测验系统。用户上传 Word、PDF 或 TXT 题目文档后，系统自动识别题目，允许人工核对，再保存为题库。用户可以立即练习、进行模拟考试，并针对薄弱考点生成基础相似题。

首版重点是开箱即用、识别结果可检查、复习流程短。系统不要求登录，不依赖云端服务。

## 2. 首版范围

### 会完成
- 上传 `.docx`、`.pdf`、`.txt` 文档。
- 自动识别单选题、多选题、判断题、填空题和简答题。
- 提取题干、选项、参考答案、解析和考点。
- 在题目入库前显示核对页面，允许修改识别结果。
- 保存题库、文档信息、测验记录和错题记录。
- 提供练习模式和模拟考试模式。
- 按考点、题型、数量生成测验。
- 根据原题和考点生成基础相似题。
- 提供模型设置入口，可填写兼容 OpenAI 格式的接口地址、密钥和模型名。

### 暂不完成
- 扫描图片和拍照题目的识别。
- 真正调用外部模型生成题目。
- 账号登录、云端同步和多人协作。
- 复杂公式编辑和自动批改主观题。

## 3. 使用流程

1. 用户进入首页，上传一个或多个复习文档。
2. 系统读取文档内容，识别题目、答案、解析和考点。
3. 系统展示识别结果，并标记不确定内容。
4. 用户检查、修改并确认入库。
5. 用户选择练习模式、模拟考试或相似题强化。
6. 系统记录答题结果、错题和薄弱考点。
7. 用户可在记录页面继续强化薄弱内容。

## 4. 页面结构

### 首页
- 显示上传区域和支持格式。
- 展示已导入题库、近期测验和薄弱考点摘要。
- 提供“开始速测”入口。

### 识别核对页
- 按题目逐条展示识别结果。
- 支持修改题型、题干、选项、答案、解析和考点。
- 明确标出需要人工确认的题目。
- 确认后一次性保存到题库。

### 题库页
- 支持按来源文档、考点和题型筛选。
- 支持编辑、删除和查看题目。
- 支持从筛选结果直接生成测验。

### 测验设置页
- 可选择练习模式或模拟考试模式。
- 可设置题目数量、题型和考点。
- 可选择使用原题或基础相似题。

### 答题页
- 练习模式每次显示一道题，提交后立即展示答案和解析。
- 模拟考试模式连续答题，统一交卷后展示结果。
- 简答题显示参考答案，用户自行对照，不自动计分。

### 记录页
- 展示历史成绩、错题和薄弱考点。
- 可从错题或薄弱考点快速发起强化练习。

### 模型设置页
- 提供接口地址、密钥、模型名输入框。
- 首版清楚标注“暂未启用联网生成”。
- 密钥不在页面中明文回显。

## 5. 系统结构

系统分为浏览器页面和本机服务两部分。

### 浏览器页面
- 负责上传资料、核对题目、开始测验和查看记录。
- 页面风格简洁，突出当前任务，减少不必要选项。

### 本机服务
- 负责读取文档、识别题目、保存题库和统计答题记录。
- 本机启动后，通过浏览器访问。
- 使用本地 SQLite 数据库保存长期数据。

## 6. 文档识别

### 文档读取
- Word 使用 `.docx` 文本段落和表格内容。
- PDF 使用可复制文本层。
- TXT 按文本内容直接读取。
- 如果 PDF 没有可读取文字，提示用户首版暂不支持扫描件。

### 题目拆分
- 优先识别常见编号，例如 `1.`、`1、`、`（1）`、`一、`。
- 识别连续的 `A.`、`B.`、`C.`、`D.` 作为选项。
- 识别“答案”“参考答案”“解析”“考点”等常见标签。
- 无选项且带空白线或括号空位时，优先判断为填空题。
- 带“正确 / 错误”“对 / 错”答案时，优先判断为判断题。
- 无选项的开放式问题默认识别为简答题。

### 不确定内容
- 不能可靠判断题型、答案或选项边界时，标记为“需要确认”。
- 系统不静默丢弃疑似题目。
- 保存前必须经过核对页面。

## 7. 基础相似题

首版不调用外部模型，只生成可用于强化练习的基础变体：

- 选择题：调整选项顺序，并保留正确答案映射。
- 判断题：在适合的题目上切换肯定或否定问法，并同步答案。
- 填空题：根据答案在题干中的位置生成挖空变体。
- 简答题：围绕相同考点使用固定模板调整提问角度。

所有相似题都会标记来源原题，并在答题后显示原题参考内容。系统不会把无法可靠变换的题目强行改写。

## 8. 数据保存

使用本机 SQLite 数据库保存：

- 上传文档信息。
- 原始题目和人工修正后的题目。
- 题目选项、答案、解析和考点。
- 测验记录和每道题的答题结果。
- 错题记录和薄弱考点统计。
- 模型设置。

首版只面向当前电脑使用，不提供账号体系。

## 9. 错误处理

- 上传不支持的格式时，明确提示支持的格式。
- 文档读取失败时，显示失败原因，不保存半成品题库。
- PDF 没有文字层时，提示扫描件暂不支持。
- 未识别到题目时，提示用户检查文档格式。
- 测验中断后，保留已经提交的答题记录。

## 10. 验证标准

完成后至少验证以下内容：

- 可上传并识别代表性的 Word、PDF、TXT 文档。
- 单选、多选、判断、填空、简答题均能入库。
- 不确定题目会进入人工核对流程。
- 练习模式能够逐题提交并立即显示答案。
- 模拟考试能够统一交卷并显示结果。
- 答题记录、错题和薄弱考点能够保存并再次打开。
- 基础相似题不会破坏选择题正确答案映射。
- 模型设置可以保存，页面明确说明首版不联网调用。
- 主要页面在浏览器中显示正常，常用按钮可完成对应操作。
